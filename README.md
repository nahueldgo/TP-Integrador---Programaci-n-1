Comisión 2

En este repositorio se encuentra el TP Integrador junto con el video, donde abordaremos una investigacion sobre el Analaisis de Algoritmos. Este trabajo compara distintos algoritmos de ordenamiento para analizar cómo cambia su rendimiento según el tamaño de los datos. Se eligió este tema por su importancia práctica en la programación, especialmente al manejar grandes cantidades de información. Mediante un ejemplo práctico en Python, se busca entender mejor el funcionamiento de estos algoritmos y afianzar los contenidos vistos en clase.
